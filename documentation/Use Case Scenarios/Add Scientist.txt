Add Scientist
Context
Scientist is logged in and in create project page

Primary Flow
1. User selects a scientist from the list of available scientists
2. User indicates that they want to add a scientist to the project
3. User enters in name and location for the project
4. User indicates that they want to create a project with the specified scientists
5. System verifies the entries
6. System displays success popup message

Alternative Flows

Empty available scientists list

A1. There are no available scientists in the system and the user is presented with an empty list
A2. Return to Primary Flow step 3

User leaves Page
A3. User hits the Back button
A4. Return to Primary Flow step 1
