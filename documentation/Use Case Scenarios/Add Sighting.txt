Add Sighting
Context
Scientist/Contributor/ is logged in and on the landing page

Primary Flow
1. User indicates that they want to add a new sighting to the system
2. System prompts user to enter latitude, longitude, date, time, and additional notes and select a animal and location for a new sighting
3. User indicates that they want to submit the data
3. System verifies submission
5. System displays a success popup message 

Alternative Flows

Missing/Empty Credentials

A3. User provides incomplete credentials (i.e., only location, or only date ...)
A4. User is unable to submit credentials
A5. Return to Primary Flow step 2

Time slot already exists

A4. System displays error popup message saying that there is already a sighting with that time slot (same day, hour, and minute)
A5. Return to Primary Flow step 2

User leaves Page
A3. User hits the Back button
A4. Return to Primary Flow step 1
